# Settings

Generated by `scripts/settings_doc.py` from `qcopt.options`; do not edit by hand.

Settings are `group.key` (a dict per group) or top-level scalars. Atomic units (bohr, Hartree) unless the unit column says otherwise. *Tier*: `common` settings are the ones most runs change; `expert` ones rarely need changing. `qcopt.default_options(calctype)` returns the same defaults, `qcopt.options_schema(calctype)` the JSON Schema.

## Minimization (`calctype="optimization"`)

A minimization (`calctype="optimization"`): RS-RFO.

| setting | type | default | unit | tier | meaning |
|---|---|---|---|---|---|
| `coordinate_system` | `auto`, `tric`, `dlc`, `cartesian` | `auto` |  | common | `tric`: delocalized internal coordinates with each fragment's translation and rotation (Wang and Song, 2016); `dlc`: delocalized internals with fragments joined by extra bonds; `cartesian`: Cartesians without rigid motion; `auto`: TRIC, or Cartesians when atoms are frozen or there are fewer than three. |
| `threads` | int or None | off |  | common | CPU threads of the calculation, at most its caller's: its gradient and Hessian calculations run on them (qcopt's own steps take one). Default: the caller's whole count (at top level, the runner's threads). |

### `hessian`
